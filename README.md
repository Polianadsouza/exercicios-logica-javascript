# Lógica de Programação e Algoritmos com JavaScript

Repositório criado para armazenar os exercícios e atividades desenvolvidos durante meus estudos de **Lógica de Programação e Algoritmos com JavaScript**, com base no livro *Lógica de Programação e Algoritmos com JavaScript*.

## 📚 Sobre

Neste repositório estão minhas resoluções dos exercícios propostos ao longo do livro. O objetivo é praticar os fundamentos da programação, desenvolver o raciocínio lógico e aprimorar a capacidade de resolver problemas utilizando JavaScript.

## 🧠 Conteúdos estudados

- Variáveis e constantes
- Tipos de dados
- Operadores
- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Arrays
- Funções
- Strings
- Objetos
- Algoritmos
- Resolução de problemas
